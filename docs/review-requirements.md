# 活动描述与状态规则 / Описание и статусы встречи

## FR-DESC 活动描述 / Описание встречи

先去掉首尾空白，再检查长度。按Unicode码点计数，允许10到1000个字符，包含两个边界；通过后返回处理后的文本。
Сначала удаляются краевые пробелы. Длина в кодовых точках Unicode должна быть от 10 до 1000 включительно. При успехе возвращается обработанный текст.

| 输入 / Ввод | 错误码 / Код |
| --- | --- |
| None、空串或全空白 / None, пустая или пробельная строка | DESCRIPTION_REQUIRED |
| 非字符串 / Не строка | INVALID_DESCRIPTION_TYPE |
| 少于10个字符 / Меньше 10 символов | DESCRIPTION_TOO_SHORT |
| 超过1000个字符 / Больше 1000 символов | DESCRIPTION_TOO_LONG |

OpenAPI中的minLength和maxLength针对去掉首尾空白后的值。
minLength и maxLength в OpenAPI относятся к очищенному значению.

## FR-STATUS 活动状态 / Статусы встречи

只有组织者能修改状态，普通参与者没有权限。
Статус может менять только организатор. Участнику это запрещено.

| 当前状态 / Текущий статус | 可转到 / Разрешённый переход |
| --- | --- |
| draft | published、cancelled |
| published | completed、cancelled |
| completed | 无 / Нет |
| cancelled | 无 / Нет |

重复设置当前状态也算非法转换。
Повторная установка того же статуса тоже запрещена.

| 情况 / Ситуация | 错误码 / Код | 约定HTTP状态 / HTTP |
| --- | --- | --- |
| 状态不存在或类型错误 / Неизвестный статус или неверный тип | INVALID_STATUS | 400 |
| 不是组织者 / Не организатор | ROLE_FORBIDDEN | 403 |
| 转换不允许 / Переход запрещён | INVALID_STATUS_TRANSITION | 409 |

## 审查重点 / Что проверить

1. 描述边界9、10、1000、1001，以及空值、空白和类型错误。
   Границы 9, 10, 1000, 1001, пустой ввод, пробелы и тип.
2. 所有状态组合、普通参与者权限、已结束和已取消的状态。
   Все пары статусов, права участника, завершённое и отменённое состояния.
3. 代码、测试和OpenAPI是否一致；原活动列表与报名接口是否保留。
   Согласованы ли код, тесты и OpenAPI, сохранены ли исходные API списка и записи.
