# 文档检查 / Проверка документации

```sh
python -B -X utf8 tools/check_docs.py
```

脚本检查必需文件、Markdown 相对链接和 PNG 文件头。通过时输出 PASS，退出码为 0。
Скрипт проверяет обязательные файлы, относительные ссылки Markdown и заголовки PNG. Успех обозначается PASS и кодом 0.
