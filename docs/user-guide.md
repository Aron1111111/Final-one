# 用户指南 / Руководство пользователя

## 启动 / Запуск

在项目根目录运行下列命令，然后打开 http://127.0.0.1:8000 。
В корне проекта выполнить команду и открыть http://127.0.0.1:8000 .

```sh
python -m bookclub.web_app
```

## 查看与报名 / Просмотр и запись

1. 点击“Смотреть встречи”，查看主题、时间和地点。
   Нажать «Смотреть встречи» и проверить тему, время и место.
2. 选择“Участник”（参与者），在已发布活动上点击“Записаться”。
   Выбрать роль «Участник» и нажать «Записаться» для опубликованной встречи.
3. 成功后按钮显示“Вы записаны”。刷新后再次提交同一报名，接口返回 409。
   После успеха кнопка показывает «Вы записаны». Повторная запись после обновления возвращает 409.

## 修改状态 / Изменение статуса

切换到“Организатор”（组织者），点击卡片上的目标状态。草稿可发布或取消，已发布活动可结束或取消；已结束与已取消的活动不能再转换。
Выбрать «Организатор» и целевой статус. Черновик можно опубликовать или отменить, опубликованную встречу — завершить или отменить. Из конечных состояний переходы запрещены.

## 数据与错误 / Данные и ошибки

演示使用固定令牌 `member-demo` 和 `organizer-demo`。报名和状态保存在服务内存中，重启后恢复示例数据；刷新页面不会重启服务。
Используются демонстрационные токены `member-demo` и `organizer-demo`. Данные хранятся в памяти сервера и сбрасываются при его перезапуске. Обновление страницы не перезапускает сервер.

- 401：令牌缺失或无效。 / 401: токен отсутствует или неверен.
- 403：当前角色不能修改状态。 / 403: роль не может менять статус.
- 404：活动不存在。 / 404: встреча не найдена.
- 409：重复报名或状态转换不允许，查看错误码。 / 409: дубль записи либо запрещённый переход; проверить код ошибки.
