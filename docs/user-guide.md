# 用户指南 / Руководство пользователя

本文记录活动查看与报名的设计流程。
Здесь описаны проектные сценарии просмотра встреч и записи.

## 查看活动 / Просмотр встреч

前提：活动列表服务可访问。打开活动列表，查看主题、时间和地点，选择要参加的活动。
Условие: сервис списка доступен. Откройте список, проверьте тему, время и место и выберите встречу.

预期：显示活动；没有活动时显示空列表。接口 GET /meetings 正常返回 200。
Ожидается список встреч либо пустой список. Успешный GET /meetings возвращает 200.

## 报名活动 / Запись на встречу

前提：参与者已经登录，活动存在，尚未报名。
Условие: участник вошёл, встреча существует и запись ещё не создана.

1. 打开活动详情，核对主题、时间和地点。
   Откройте встречу и проверьте тему, время и место.
2. 点击一次报名操作，等待页面返回结果。
   Выполните запись один раз и дождитесь ответа страницы.
3. 查看报名确认；提醒邮件延迟不应触发重复报名。
   Проверьте подтверждение записи; задержка письма не требует повторной записи.

若未收到确认，先联系活动管理员核对报名记录，提供活动名称和提交时间，再决定是否重试；不要连续重复点击。
Если подтверждение не получено, сообщите администратору встречи её название и время отправки, уточните наличие записи и только затем решайте, нужно ли повторять. Не нажимайте кнопку многократно.

预期：创建一条报名，接口返回 201。系统在事务提交后安排提醒；提醒故障不代表报名失败。
Ожидается одна запись и ответ 201. Напоминание планируется после транзакции; сбой письма не означает отмену записи.

## 异常处理 / Ошибки

- 401：重新登录后再操作。 / 401: повторно войдите.
- 404：返回列表，重新选择存在的活动。 / 404: выберите существующую встречу.
- 409：已经报名，勿重复提交。 / 409: запись уже существует, повторять не нужно.
